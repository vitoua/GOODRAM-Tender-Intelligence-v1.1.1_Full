# GOODRAM Tender Intelligence v1.1.1

Full build based on v1.1, with all prior modules restored.

- TED, Prozorro and Germany OCDS connectors
- Poland retained in UI and monitored through TED
- 177 editable CPV filters
- Editable PL/UA/EN keyword filters
- Strict Prozorro CPV/keyword filtering
- Minimum value default EUR 50,000, editable
- Publication date default 30 days back, editable
- Polish default UI plus PL/UA/EN/ES switch
- Optional LibreTranslate integration and original/translated view
- Indexed deduplication and preserved source links
- Analytics dashboard with filters and charts
- Excel export of the currently filtered tender list
- Sources and About pages
- Designed and developed by Vitaliy Drofyak
